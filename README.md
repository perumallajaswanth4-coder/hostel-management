# 02 Online Course Website

A responsive online learning platform concept built with HTML and CSS.

## Run locally
Open `index.html` in a modern browser. Keep `style.css` in the same folder.

## Deploy with GitHub Pages
Open repository **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

## Customize
Replace demo course names, instructor profiles, prices, reviews, and contact details before presenting.
